Abstract

Comparing attribution graphs offers a way to ask whether differently worded questions recruit shared model features. We tested how this overlap relates to the requested fact and the predicted answer in Gemma-2-2B, Qwen3-1.7B, and Qwen3-4B. Reworded questions about the same fact had higher mean feature overlap than questions about other facts in all three analyzed samples, including after equalizing feature counts. Because those comparisons also shared words and expected answers, we tested Qwen3-4B with identical word and token inventories within each of six country pairs while varying the queried country, wording, and correct A/B answer. All 48 predicted letters were correct. The same-country minus different-country overlap was 0.0628 when the answer letter stayed the same and -0.0022 when it changed. Their average, the prespecified primary outcome, was 0.0303 (95% block-bootstrap interval 0.0265–0.0338). In a separate exploratory diagnostic using one country pair, all eight selected wrong-answer graphs shared more features with a correct prediction giving the same answer than with a correct prediction for the intended country. Together, the experiments identify an answer-associated pattern in feature overlap that persists in selected errors. This supports interpreting overlap jointly with the prompt comparison and predicted answer, rather than as a standalone marker of correct factual processing. The stronger comparisons concern Qwen3-4B geography; a failed history pilot prevented the planned historical graph evaluation.

1. Introduction

Knowing whether a language model gives a correct answer does not explain how it arrived at that answer. Mechanistic interpretability seeks to address this question by examining the computations inside a model [1]. For factual questions, this raises a more specific question: when different prompts ask about the same fact, what remains similar in the model’s internal activity?

Attribution graphs show patterns of activity inside a model and estimate how those patterns contribute to its prediction. These learned patterns are called features [1]. Previous research has examined how model computations vary across prompts [2]. Studies of multiple-choice questions have also shown that rearranging answer options can change which answer a model selects [5]. These findings motivate examining how differences between questions and their predicted answers relate to the features found in attribution graphs.

Comparing these graphs requires distinguishing what the questions and answers have in common. For example, two rewordings of a question about France’s capital both expect Paris. Their graphs might share features because they ask about the same fact, use some of the same words, or predict the same answer. We therefore need comparisons that ask about the same fact while changing the model’s required output.

We initially hypothesized that, within each model, differently worded questions about the same fact would share more attribution-graph features than questions about different facts. We tested this association in Gemma-2-2B, Qwen3-1.7B, and Qwen3-4B. We measured feature sharing using Jaccard similarity, our measure of feature overlap: the proportion of all distinct features across two graphs that appears in both. It compares the features present, not the connections between them.

We then used Qwen3-4B to examine this association with stronger controls for shared words and answers. For multiple-choice questions using the same two countries, we kept the words and their counts the same while varying which country was asked about and whether the model had to answer A or B. Changing the letter assigned to a capital allowed the factual answer to remain the same while the required response changed. We also examined selected incorrect predictions, comparing their graphs with correct predictions for the intended country and correct predictions giving the same answer for another country.

Feature overlap was associated with both the relationship between questions and the answer the model predicted. We next describe the model samples, question designs, and graph comparisons used to evaluate these relationships.

2. Methods

We organized the study around three comparisons (Figure 1). First, we compared reworded questions about the same fact with questions about different facts across all three models. Second, we gave Qwen3-4B multiple-choice questions and swapped the capitals assigned to A and B. This changed the required answer letter without changing the capital being asked for. We then tested whether questions about the same country still shared more graph features than questions about different countries. Third, also using Qwen3-4B, we examined attribution graphs for incorrect predictions, referred to here as error graphs. Each error graph was compared with two graphs for correct predictions: one giving the correct answer for the intended country, and one giving the same answer as the error, but in a context where that answer was correct. The three analyses used distinct question sets and were evaluated separately.

2.1 Models, questions, and collected data

We analyzed attribution graphs from three language models: Gemma-2-2B, Qwen3-1.7B, and Qwen3-4B. Neuronpedia ran the models and generated the graphs remotely. We analyzed the saved graphs locally, without running the models on our own hardware. Within each model, we compared feature sharing between reworded questions about the same fact with feature sharing between questions about different facts. We used the same Jaccard similarity measure and feature-exclusion rules across all three models, providing a separate test of the same hypothesis in each model.

The question/control design included 30 facts, with ten each from chemistry, geography, and history. Each fact had a starting question, a reworded question asking for the same fact, and two invented name controls. These controls replaced the real name with an invented name while preserving either the starting or reworded sentence pattern. Within each subject, five facts were assigned to development and five to evaluation. All four question versions for a fact stayed in the same set. Development questions supported method development and diagnostic checks; evaluation questions provided the primary test of whether rewordings of the same fact shared more features than questions about different facts.

2.2 Measuring feature overlap

We measured feature sharing between questions using Jaccard similarity, our measure of feature overlap. This is the number of shared features divided by the total number of distinct features across both graphs. The score ranges from zero, when no features are shared, to one, when both graphs contain the same features. It compares the features present, not the connections between them.

For each graph, we identified distinct learned features using the tuple (feature family, layer, feature ID). Matching numerical IDs in different layers or feature families remained distinct. A feature that appeared at multiple positions in the input was counted once. We excluded input representations (embeddings), output prediction scores (logits), and reconstruction-error nodes, which represent activity not captured by the learned features. We also excluded nodes with missing or duplicated graph-node identifiers. Features were compared only between graphs from the same model.

For each starting question, we calculated Jaccard overlap with its factual rewording. We then calculated its overlap with the reworded questions for every other included fact from the same model, subject, and development or evaluation set. Our primary outcome was the same-fact overlap minus the average of these other-fact overlaps. A positive difference therefore indicated greater feature sharing with the same-fact rewording. Figure S8 summarizes the workflow.

Let T_i and P_i denote the feature sets from the graphs for a starting question and its factual rewording, respectively. Their same-fact overlap minus the average other-fact overlap is:

M_i = Jaccard(T_i, P_i) - mean_{j ≠ i} Jaccard(T_i, P_j),

where j includes every other included fact in the same model, subject area, and development or evaluation set.

A fact was included only when all four question and control graphs were available. For both factual prompts, the model’s highest-probability next token had to match the expected token after removing leading and trailing whitespace, such as spaces or line breaks. At least one other fact also had to meet these conditions within the same model, subject area, and development or evaluation set, providing the other-fact comparison. This is a next-token matching rule, not verification of a complete generated answer.

Zero means equal overlap; negative values mean more shared features in the other-fact comparison. The outcome is a difference between Jaccard scores, not a percentage increase. Other designs below specify their own subtraction; weighted cosine comparisons are called differences in weighted similarity rather than feature overlap.

For each model, we summarized the evaluation-fact differences by their mean and a descriptive 95% percentile bootstrap interval, using 10,000 resamples of the calculated fact-level differences with replacement. Exact one-sided sign-flip tests assessed whether the mean difference was greater than zero. Complementary within-domain fact-label permutations assess matched assignment without treating graph pairs as independent samples. Facts reuse comparators, sign-flip assumptions require care, and the same facts recur across models: 8+10+10 represents 28 model-specific fact observations, not 28 unique independent facts. No pooled model-ranking test is performed.

2.3 Crossed design and controls

To examine how feature sharing varied with the requested fact and its wording, we analyzed three facts from each of three subject areas in Gemma-2-2B and Qwen3-4B. Each fact had an original question and two rewordings, giving 27 graphs per model. We labeled these versions “original,” “alternative 1,” and “alternative 2.” We compared questions about the same fact across different versions, and questions about different facts within the same labeled version. Both comparisons used questions differing in fact and version as their baseline. The version labels did not imply identical sentence patterns across facts. We calculated overlap differences within each subject area and then averaged across areas, using permutation tests that preserved these groupings. Their relative sizes were descriptive, not tests that wording mattered more than the fact being asked about or that the models differed.

Invented name controls replace a real entity name with an invented name (for example, replacing “gold” with “zorium”) while retaining either the starting sentence pattern or its reworded version. A separate sensitivity check compares outputs only within broad next-token categories: letters/numbers, whitespace, or punctuation/symbols. This does not match the exact answer, its meaning, or its probability.

2.4 Exploratory confound checks

Raw-file hash checks cover all 383 graphs in the question/control and fact/wording datasets. Collision-safe feature counts were checked against the saved audits, and archived per-fact contrasts were reconstructed to absolute tolerance 1e-12. Section 2.8 and the reproducibility records describe the Qwen3-1.7B verification.

Feature counts. Within each model/domain/held-out block, K is the smallest target or positive-paraphrase feature count. Each graph is independently subsampled without replacement to K or floor(K/2). Across 200 repetitions (seed 20260905), a sampled graph is reused in all its comparisons. We report per-fact averaged margins, descriptive 10,000-resample fact-level bootstrap intervals, and separately the variability across subsampling repetitions. Equal cardinality does not equalize feature-selection bias or remove lexical confounding.

Shared words and answer identity. Word overlap is case-folded alphanumeric word-set Jaccard, without stopword removal. Other-fact comparators must either equal or exceed own-paraphrase word overlap, fall within an absolute 0.05 caliper, or satisfy that caliper plus a feature-count ratio within 1.25 of the own paraphrase. All qualifying comparators are averaged. No support is reported as not estimable, not zero. Calipers were not widened after inspection. Expected-answer identity is separately tabulated.

Tokenizer audit. Official Qwen tokenizer revisions were pinned and their files hashed. Their single-token decodings were checked against archived prompt pieces and top logit IDs. Expected continuations were encoded against each stored prompt with zero or one separating space, requiring prefix stability. Whole-answer next-token matches, substantive multi-token prefixes, whitespace-only compatibility, and mismatches under those conventions remain distinct. Historical tokenizer revision identity is not fully recoverable, and current-tokenizer compatibility is not proof of a completed answer. Gemma’s official tokenizer download returned HTTP 401; its tokenizer-aware classification remains unavailable. No mirror or local weights were used [3,4].

For crossed output sensitivity, a domain must retain all nine cells under the original strict string rule. We do not select individual favorable cells or replace the original cohort.

2.5 Matched-choice follow-up separating queried country and answer label

To make this comparison, we gave Qwen3-4B multiple-choice questions containing two country names and two possible capitals, labeled A and B. Each question asked for the capital of one of those countries. Changing which capital was assigned to each letter allowed us to change the required output without changing the underlying fact. For illustration, a question about France’s capital requires A when Paris is labeled A, but B when Paris is labeled B. Across questions using the same two countries, we kept the words and word counts the same but varied which country was asked about, the word order, and the assignment of capitals to A and B. We could therefore compare feature overlap when questions asked about the same country but required either the same or different answer letters.

We used Qwen3-4B’s non-thinking chat format. Within each of six country pairs, we varied the country asked about, the assignment of capitals to A/B, and the wording, producing eight graphs per pair. Each prompt contained the same words and the same counts of tokenizer IDs within its pair, although order and country roles changed. France/Germany was used only in the preliminary behavioral check for this experiment. We measured same-country minus different-country overlap separately for comparisons with the same and different answer letters. The prespecified primary outcome was the average of these two differences. Uncertainty used six country pairs, not 48 independent graphs. The exact conditional fact-correspondence test contained 4096 assignments; its locally frozen multiple-testing adjustment covered three model/version opportunities.

The follow-up design was informed by earlier results, but its rules were fixed before collecting its evaluation graphs. Earlier plain-completion pilots had failed: Qwen3-4B chose A on all eight items, giving 4/8 correct labels, while Gemma produced the correct capitals but none of the eight requested letters. These failed pilots remain separate from the original cohorts. The revised Qwen study controls word and token inventories and varies answer labels, but does not remove differences in query order or how country names are assigned roles.

2.6 Position pilot and exploratory failure-case diagnostic

Research on position-based retrieval has documented difficulties identifying items by list position, particularly when counting backward [7]. Our position-based analysis asked about a country’s position in a list while varying the queried country, list order, answer mapping, and wording. Its prespecified accuracy requirement had to be met in a 16-item pilot before collecting evaluation graphs. After the pilot failed, we conducted an explicitly exploratory diagnostic of selected errors; this was not a replacement evaluation cohort.

We investigated selected cases by generating attribution graphs and checking that the incorrect predictions occurred again. For example, with France listed before Germany, asking for the first country’s capital incorrectly produced Berlin. Naming France directly produced Paris, whereas naming Germany produced Berlin. Both named-country predictions were correct for their respective questions. Comparing their graphs with the incorrect prediction’s graph let us ask whether feature sharing was greater with the intended fact (France’s capital is Paris) or with the answer the model actually predicted, Berlin.

The diagnostic contained 20 next-token previews: four literal/replay positive controls and four selected France/Germany cases varied by how the country was identified (its name or list position) and by response format (A/B letter or capital name). These cases were selected because the correct answer conflicted with choosing an answer option by its position. We fixed the 16 diagnostic prompts before generating their graphs. Each wrong-answer graph was compared with two correct-answer graphs: one for the intended country and one producing the same answer as the error. Both controls preserved the option layout and country-list order. The position-based and named-country prompts differ in wording, length, and repeated names; unlike the matched-choice experiment, their word and token inventories are not identical.

Graph settings were maxNLogits=10, desiredLogitProb=0.99, nodeThreshold=0.8, edgeThreshold=0.85, and maxFeatureNodes=5000, using hosted Qwen3-4B with the recorded transcoder source. Exact prompts and token sequences, source/settings, checksums, identifier integrity, and observed answers were audited. Wrong answers were deliberately retained. All comparisons report feature-set Jaccard, exported-influence-weighted cosine, and an equal-feature-count sensitivity using 200 repetitions with fixed seeds. Direct incoming edges to the observed answer logit were summarized by source type and token location, preserving signs and absolute weights. Display panels retain the ten largest absolute direct edges and the ten largest upstream edges into those displayed predecessors; full tables retain the remaining edges.

These selected cases concern two facts in one country pair, with reused controls. We report descriptive comparisons without confirmatory p-values or population confidence intervals. The country-location weight ratio discussed below was an additional descriptive inspection of the archived role tables, not a prespecified primary endpoint. All outcomes concern the top next token under the hosted non-thinking setup; they do not independently establish full generated-answer behavior [6]. Local provenance checks also do not independently certify hosted-weight identity.

2.7 Final saved-data audit and separate history follow-up

After inspecting the matched-choice results, we directly compared the same-label and changed-label fact contrasts across the six country-pair blocks. We report the mean paired difference, a 20,000-resample block-bootstrap interval, a Student-t interval, and a two-sided exact block sign-flip test. These summaries assume independent blocks; the sign-flip null additionally assumes symmetric block contrasts. This added test is exploratory and is distinct from the original conditional correspondence test. The 4,096 correspondence assignments are null configurations within six blocks, not 4,096 independent observations.

The tests answer different questions:

Test Question and outcome Reference distribution and interpretation
Prespecified conditional correspondence test Is the average of the two fact contrasts greater than expected under reassigned fact correspondence? Primary mean: 0.0303. Reassign queried-fact correspondence across wording versions within each answer-label group: four assignments per country pair and 4096 across six pairs. The reference null treats those assignments as exchangeable conditional on the label and word inventory. It tests correspondence under that null, not a causal effect isolated from word order or country roles.
Exploratory block sign-flip test Is the same-letter fact contrast different from the changed-letter fact contrast? Paired mean difference: 0.0650. Flip the sign of each of six country-pair differences, assuming independent blocks and symmetric differences under the null. The two-sided test concerns the difference between conditions, not their average.

The conditional test’s small p-value describes the specified reassignment null; it does not establish that the prompts are exchangeable for every substantive hypothesis. Residual order and role differences constrain interpretation. The question/control comparisons also reuse other-fact comparators, so their resampling results are reported alongside the within-domain correspondence tests rather than as independent replications.

As graph-location sensitivities, we removed feature nodes at the final prediction context position, in the last quarter of observed feature layers, or both, before collapsing feature identities. Empty representations are unavailable rather than assigned zero overlap. These filters test concentration of the measured association; they are not causal ablations, and retained graphs remain conditioned on the generated output. We applied the same filters to the selected failure comparisons without attaching population p-values to their dependent triples.

A final historical-date study was locally frozen on 5 October before its hosted outcomes. It used Qwen3-4B only, two separate pilot event pairs plus four literal-label checks, and a planned evaluation of 20 event pairs spanning US documentary history and spaceflight chronology. All eight prompts per pair had identical token inventories; queried event, year-to-label mapping, and question/context order varied. The protocol required all 20 pilot checks to pass before any of the 160 evaluation graphs could be requested. Its planned primary endpoint was the mean same-label minus changed-label fact contrast, conditional on complete correct-answer blocks, with at least 16 supported blocks including six per theme. The failed pilot stopped collection, so this endpoint was not measured. This prospective, outcome-informed follow-up does not change original history inclusion.

2.8 Qwen3-1.7B analysis and verification

The Qwen3-1.7B results use the combined 91-graph dataset, with the representation, inclusion rules, and comparisons within the same subject area in Section 2.2. Its ten evaluation facts supply the estimates shown throughout the current figures and tables. Analysis settings were recorded before calculating these estimates, but after earlier findings were known; these analyses are exploratory rather than an independent confirmatory replication. Verification included raw-file hashes, agreement with archived feature representations, and reconstruction of previously calculated per-fact Jaccard and influence-weighted contrasts to absolute tolerance 1e-12. Earlier estimates remain in the archive and are not counted as additional evidence.

Graphs used the recorded llamascope-2-transcoder-16k-k64 source and LoRSA feature family, with at most ten candidate next tokens (maxNLogits=10), node and edge thresholds of 0.8 and 0.85, and a 5,000-feature-node cap. LoRSA tracing settings were qkTopFraction=0.5 and qkTopk=5. Desired cumulative output probability was 0.99 for the completion requests; some archived files used 0.95 output coverage. We preserved those files and their source and exporter metadata rather than assuming identical hosted versions. Raw-file audits checked identifiers, edge endpoints, duplicate edges, and finite numerical values. No shorter prompts or replacement questions were introduced.

The primary contrast was same-fact minus average other-fact Jaccard overlap. We used 10,000 fact-level bootstrap resamples, exact one-sided sign-flip tests, and exact fact-label permutations within each subject area, with main seed 20260714. The evaluation permutation enumerated 5! × 5! = 14,400 assignments. Bootstrap intervals and sign-flip tests describe fact-level differences that share comparison questions; the permutation assumes exchangeable factual pairings within each subject area. Holm correction was applied to the 15 secondary metric/contrast tests, excluding the primary comparison. This family crossed four metrics (feature Jaccard and cosine similarities of influence-weighted features, layer profiles, and layer-to-layer edge flow) with four comparators (average other fact, most similar other fact, same-pattern invented name, and reworded invented name), minus the primary Jaccard/average-other-fact test. Output-type-matched subsets, error-inclusive and equal-count checks, and subject-specific summaries were outside this correction family. These exploratory summaries do not remove shared-word or expected-answer differences.

Sensitivity analyses retained both invented name controls, comparisons matched by broad next-token category, the most similar other-fact comparator, exported-influence-weighted cosine, reconstruction-error-inclusive representations, layer profiles, and layer-to-layer edge-flow summaries. Feature weights summed absolute exported influence across occurrences; layer profiles aggregated that influence by layer, and edge-flow profiles aggregated absolute edge weights between eligible feature nodes by source and target layer. Output-type matching required the control and starting question to have the same broad next-token category, retaining nine same-pattern and ten reworded-control comparisons. Equal-feature-count checks reused Section 2.4’s 200 subsamples at K and floor(K/2), with seed 20260905 and K defined separately within each subject’s evaluation set. The subsamples were not treated as additional facts. Leave-one-fact-out summaries removed one already-calculated difference at a time without rebuilding its comparison pool.

Retrospective saved-data audits used the export, word-matching, and tokenizer procedures in Section 2.4. Export checks covered all 91 graphs; word-matching checks covered the ten included evaluation facts; token checks covered all 50 available factual starting/reworded prompts, including development questions and partial history sets. Reconstruction-error influence was summarized as absolute error-node influence divided by absolute nonterminal-node influence, not an answer-error rate. The archived tokenizer and unchanged word-matching rules were reused. Compatible answer beginnings remained distinct from complete expected next-token answers, and these audits did not alter inclusion or primary estimates. Audit plans and their timing relative to the overlap analysis are retained in the provenance records. Other models and the separate fact-by-wording experiment retain their own analysis samples.

3. Results

3.1 Reworded questions about the same fact share more features

Every included evaluation question had greater overlap with its same-fact rewording than its average overlap with rewordings of other facts. Mean differences in feature overlap were 0.170 for Gemma (descriptive 95% interval [0.085, 0.276], n=8), 0.0894 for Qwen3-1.7B ([0.0820, 0.0976], n=10), and 0.162 for available Qwen3-4B cases ([0.131, 0.194], n=10). Exact sign-flip p-values were 0.00390625, 0.0009765625, and 0.0009765625; fact-label permutation p-values were 0.00139, 0.0000694, and 0.0000694, respectively. The association is consistent across these samples; their differing subject coverage and repeated facts make this a within-model result, not a model ranking.

Qwen3-1.7B showed positive overlap differences for all five chemistry and all five geography evaluation facts, with subject means of 0.0854 and 0.0935. No history fact had a complete control set. Figure 2 presents the three model samples and their subject-specific estimates. Figure S7 reports Qwen3-1.7B collection and inclusion counts, with detailed analyses in A5.

The next question is what the association distinguishes. A same-fact rewording can preserve both words and the expected answer. We therefore examined whether the controls could separate those relationships.

3.2 Same-fact questions share words and expected answers

To separate factual identity from shared wording, we looked for other-fact questions that matched each same-fact pair’s word overlap. None met any of the three word-matching or joint word/feature-count rules: 0/8 Gemma, 0/10 Qwen3-1.7B, and 0/10 Qwen3-4B. Even the most word-overlapping other-fact prompt scored at least 0.1806 below the same-fact rewording across these samples (Supplement Figure S4). The gap was not a borderline threshold result.

Answer identity was coupled to factual identity as well: none of the 106 directed other-fact comparisons shared the expected answer, whereas same-fact pairs did. This comparison changes the fact, word overlap, and expected answer together. It establishes their combined association with shared features, leaving their separate contributions unresolved.

The fact-by-wording experiment compared question pairs sharing a fact or a labeled version. Both comparisons had positive average overlap differences relative to pairs differing in both fact and version: 0.074/0.118 in Gemma and 0.101/0.064 in Qwen3-4B (Figure 3). Shared version labels did not consistently indicate identical sentence patterns across facts. Influence-weighted similarity had the same ordering within each pipeline (0.090/0.114 and 0.105/0.075). This ordering is descriptive because output quality and subject coverage vary: only Qwen3-4B geography passed the strict expected-token rule in all nine questions (Supporting analysis A1).

When controls were matched only by broad next-token category, overlap differences relative to same-pattern invented name controls were -0.069 (Gemma, n=2), -0.0109 (Qwen3-1.7B, n=9), and +0.096 (Qwen3-4B, n=10). Differences relative to reworded invented name controls were positive in all three models (Figure 4). For Qwen3-1.7B, the mean was +0.1059 across ten reworded-control comparisons. Before output-type matching, eight of its ten evaluation questions shared more features with the same-pattern invented name control than with their factual rewording; seven of nine did so in the matched subset. All ten favored the factual rewording over the reworded invented name control. These contrasting results motivate a follow-up that preserves the available words while varying the requested country and the answer letter.

3.3 Same-fact overlap is higher when the answer letter stays the same

We next tested the same-country association with a shared answer and with a changed answer. In Qwen3-4B, we kept the available words and token counts identical within each of six country pairs while varying the country asked about, the wording, and the correct A/B answer. Comparing same-country with different-country overlap within each answer condition separated the two components of the average. All 48 predicted labels were correct, and all exports passed the recorded identifier and checksum checks.

The same-country minus different-country overlap was 0.0628 with the same answer letter and -0.0022 with a changed letter. Their average, the prespecified primary outcome, was 0.0303 (95% block-bootstrap interval 0.0265–0.0338), positive in each of six country-pair blocks. The exact conditional correspondence p-value was 0.000244141, or 0.000732422 after the prespecified three-opportunity adjustment. The positive average was concentrated in the same-letter component. The changed-letter estimate was near zero; this was not an equivalence test.

When the model had to answer with different letters, questions asking for the same capital had nearly the same average feature overlap as questions about different countries. The factual answer remained the same, but the greater feature overlap observed with a shared answer letter did not persist.

Across country relationships, overlap was also higher for the same answer letter than for different letters: the descriptive difference was 0.2827. This is a separate overlap contrast, not a fraction of variance or reasoning explained.

The exploratory direct paired difference between the same-letter and changed-letter fact components was 0.0650 Jaccard units across six blocks (95% block-bootstrap interval 0.0582–0.0715; Student-t interval 0.0553–0.0746; two-sided block sign-flip p=0.03125). All six differences were positive. The difference remained 0.0720 after excluding final-position feature nodes, 0.0688 after excluding the last quarter of observed feature layers, and 0.0732 after both filters (Supplement Figure S6). The association therefore extends beyond the removed node sets. These comparisons establish an answer-associated pattern in this task; word order, answer mapping, country roles, and output-conditioned graph construction remain possible contributors.

3.4 Error graphs show greater overlap with answer-matched controls

The matched-choice study used correct predictions. We next asked what graph overlap indicates when the predicted answer is wrong. With options “A: Berlin. B: Paris” and countries “France, Germany,” asking for the first country’s capital produced A or Berlin, depending on the response format. Naming France instead produced B or Paris; naming Germany produced A or Berlin. The wrong-answer graph shared more features with the correct Germany prediction giving the same answer than with the correct France prediction.

These cases came from a separate list-position pilot that produced 8/16 correct A/B decisions and stopped at its prespecified accuracy gate. A local audit found no mismatch in expected answers, submitted prompts, token sequences, or top-token decoding. The later exploratory 20-preview diagnostic passed all four literal/replay checks. Its eight named-country prompts produced the intended next token; its eight selected position-based prompts reproduced errors across both response formats. The failed pilot’s evaluation cohort remained uncollected.

All 16 diagnostic graphs passed integrity checks and reproduced their archived preview answers. Thus all eight ordinal errors persisted, all eight named-country controls remained correct, and all eight comparison triples met the clean-export and output-matching requirements. In every triple, the failure graph shared more features with the correct same-output response than with the correct intended-country response (Figure 6). The mean same-output minus same-country Jaccard difference was 0.1983 for A/B responses and 0.2649 for capital-name responses. Equal-feature-count sensitivities retained differences of 0.1851 and 0.2361, respectively; influence-weighted cosine preserved the direction in all eight triples. These are dependent descriptive comparisons, not eight independent replications.

The same-output advantage persisted in every selected comparison under all three graph-location filters. Removing both final-position nodes and the last quarter of observed feature layers gave mean differences of 0.2053 for labels and 0.2608 for capital names (Supplement Figure S6). The resemblance was therefore present beyond the removed node sets, even though the remaining graphs were still conditioned on the predicted output.

Across these selected cases, sharing the predicted answer corresponded to greater feature overlap than sharing the intended country. The cases use one country pair and overlapping controls, so they illustrate this relationship rather than estimate an error rate. Their layouts leave position matching and mishandled negation unresolved; Supporting analysis A3 reports the source-location observations, approximation error, and missing correct-answer logits.

4. Discussion

4.1 What the comparisons establish

The experiments connect three observations. Reworded questions about the same fact share more features in the three analyzed model samples. With matched word and token inventories in Qwen3-4B, the same-country overlap difference is larger when the answer letter stays the same. In selected errors, a wrong prediction shares more features with a correct prediction giving that same answer than with a correct prediction for the intended country. The progression shows why an average same-fact association must be interpreted together with answer agreement.

The contribution is more specific than the general warning that similarity is not causality. We identify which comparison changes the interpretation: separating same-answer from changed-answer pairs exposes a pattern that the positive average conceals. The selected-error comparison then demonstrates that this resemblance can coexist with an incorrect next-token decision. Equal-feature-count sampling and graph-location filters preserve the reported average patterns, so the observations persist under these checks of representation size and location.

For analyses using feature overlap, the practical implication is to report same-answer and changed-answer comparisons separately, state what behavior was verified, and distinguish overlap with the intended fact from overlap with the predicted answer. In this study those distinctions reveal a consistent answer-associated pattern. They preserve the positive original finding while specifying what it measures.

4.2 Scope and remaining questions

Three models from two families contribute to the question/control comparison; Qwen3-4B alone contributes to the stronger controls and selected-error diagnostic. The matched-choice estimates use six country pairs. The selected errors share one pair and overlapping controls. Subject coverage differs, the Qwen3-4B question/control collection is incomplete, and the failed history pilot provides no historical graph-overlap estimate. The results concern top-next-token decisions under the recorded hosted setup, not independently verified full generated answers or replication across deployments.

The Qwen3-1.7B association is supported by chemistry and geography, alongside contrasting results for the two invented name controls. The answer-letter experiment remains confined to Qwen3-4B. Qwen3-1.7B history questions are unavailable for the controlled comparison because no complete four-version sets were returned.

Word order, answer mapping, and country roles remain potential contributors to the observed comparisons. In the selected capital-name errors, source-location weights favor the other country, whereas named-country controls favor the intended one; the A/B format does not show the same consistent pattern. Incorrect reference selection, option-position matching, and mishandled negation therefore remain alternative hypotheses. Fixed-attention attribution graphs also need not explain how the attention pattern arose [1]. This diagnostic complements earlier work on selection and positional retrieval [5,7] without establishing a new error mechanism.

Independent statistical review should assess the exchangeability and dependence assumptions described in Methods. Distinguishing position matching from negation errors would require varying those factors separately. The evidence supports an answer-associated interpretation of feature overlap in these tasks, not an absence of factual knowledge or a recovered answer-independent circuit.

4.3 Future research: separating computation from graph selection

The answer-associated pattern raises a mechanistic question: does producing the same answer token involve shared model activity, or does the graph-building method preferentially retain similar features when explaining that answer? Both processes could contribute. Attribution graphs retain features according to their influence on selected output tokens [1], so shared features may reflect both the model’s computation and how that computation is measured. The feature-count and graph-location checks show that the pattern survives those filters, but they do not undo the earlier selection of features. Decomposition and pruning therefore remain part of the explanation to be tested, rather than established causes of the observed pattern.

Future research could separate these contributions using two complementary comparisons. First, graphs explaining A and B could be constructed from the same recorded model run, holding the prompt and model activity fixed while changing only the output being analyzed. Differences would reveal dependence on the attribution target, although they would not by themselves quantify its contribution to the cross-question result. Second, the same-country and same-answer comparisons could be repeated using feature activity recorded before answer-dependent selection, retaining the same feature definitions and checking sensitivity to feature counts. Persistence of answer-associated similarity would support a contribution from shared model activity; a pattern that emerges or strengthens after selection would implicate the measurement procedure as well. Our saved exports contain only retained features and do not consistently include alternative answer tokens, so they cannot provide this complete comparison.

Causal follow-up could then test whether candidate features affect answer production across different facts or affect answers about a particular fact when its required letter changes. Such tests should use facts and wordings not used to select the features, unchanged-model controls, randomly selected feature sets matched in number, layer, and activation, and multiple intervention strengths. Selective behavioral effects would provide stronger evidence about feature function than a general change in the output. These proposed studies would explain the source of the observed association; they are future work, not experiments performed in this study.

5. Conclusion

Reworded questions about the same fact share more graph features in all three analyzed model samples. In the stronger Qwen3-4B comparison, that advantage is concentrated in pairs sharing the answer letter, and selected error graphs share more features with correct predictions giving the same answer. Feature overlap therefore captures answer-associated structure as well as the original same-fact association in these tasks. Interpreting it as evidence of factual processing requires accounting for the prompt comparison and predicted answer; overlap alone does not establish correctness.

The chemistry and geography observations therefore leave a gap in word- and answer-matched controls. These audits do not alter the inclusion rules or primary estimates.
