Figures for the integrated paper outline

Updated 7 November 2026. Six main figures and eight supplements present the current three-model dataset and its analysis workflow. The primary comparison includes 8 Gemma-2-2B, 10 Qwen3-1.7B, and 10 Qwen3-4B test questions. S8 explains the method using illustrative feature sets and scores.

A feature is a learned component represented in the exported graph, not a verified concept or a complete reasoning step. Feature overlap counts which components appear in both graphs; it does not compare all their connections. Jaccard overlap divides the number shared by the total number of distinct features across the two graphs: 0 means none shared, and 1 means identical sets. A difference in feature overlap subtracts one overlap score from another; each figure specifies the comparison. It can be positive, zero, or negative. Zero means equal overlap, not missing data.

A test question was reserved for evaluation rather than for developing the analysis. A token is one unit of predicted text; it may be a whole word, part of a word, or a symbol. A/B answer means the letter produced, not necessarily the same capital city. Category colors are explained by labels or legends; numerical colors have a scale. An asterisk on Qwen3-4B marks the incomplete original collection (145/147 graphs), not the separate completed follow-ups.

Figure 4: Invented name controls give different results across models

Replace the real name with an invented name, retaining the starting wording (A) or rewording it (B). For each test question, subtract overlap with the invented name prompt from overlap with the factual rewording. Positive values favor the factual rewording; negative values favor the invented name control. Colors identify models, points show questions, diamonds show means, and bars show saved 95% question-bootstrap intervals; n counts included questions. Panel A means are -0.069 (n=2), -0.011 (n=9), and +0.096 (n=10) for Gemma-2-2B, Qwen3-1.7B, and Qwen3-4B. For Qwen3-1.7B, the interval in A is -0.021–0.001; B has mean 0.106 (n=10; interval 0.092–0.119). The original-wording control has more overlap in 8/10 Qwen3-1.7B questions before token-type matching and 7/9 in the plotted matched subset. Matching uses only broad first-token categories (letters/numbers, whitespace, or punctuation/symbols), leaving exact answer, meaning, confidence, and correctness unmatched. Small, differently composed samples support comparison-specific findings rather than a general explanation by wording. *The Qwen3-4B collection is incomplete (145/147 graphs).

Figure 5: Same-fact overlap is higher when the answer letter stays the same

Qwen3-4B: six country pairs, 48 correct next-token A/B predictions, and identical word/token inventories within pairs. Rules were fixed before collection in this outcome-informed follow-up. A, Mean feature overlap in the four cross-wording comparisons: 0.8005, 0.4853, 0.7377, and 0.4874, read row by row. The scale runs from no shared features (0) to identical sets (1). B, Same-country minus different-country overlap is 0.0628 with the same letter and -0.0022 with a changed letter. Their paired difference is 0.0650 (exploratory Student-t 95% interval 0.0553–0.0746; two-sided sign-flip p=0.03125). C, Their average is the prespecified primary outcome: 0.0303 (95% block-bootstrap interval 0.0265–0.0338). The descriptive same-letter minus different-letter difference, averaged across country relationships, is 0.2827. Lines represent country pairs; diamonds show means. Only the primary mean in C has an interval drawn. Colors identify labeled categories; B and C use different vertical scales. Tests assume six independent country-pair blocks; the sign-flip test additionally assumes symmetric null differences. The 48 graphs and 4,096 conditional-null reassignments are not independent replicates. Near zero is not equivalence. Overlap differences are neither accuracy nor variance explained; query order, country roles, and output-conditioned graphs remain alternatives to a causal interpretation. The axis gives their share of absolute nonterminal-node influence, using the saved audit definitions. This is not the percentage of wrong answers or of reasoning explained. Box centers mark medians; boxes span the middle 50%, whiskers extend to values within 1.5 box lengths, and dots show values beyond the whiskers. Gemma and Qwen3-1.7B distributions use raw-file audits; Qwen3-4B uses converted graphs with no ambiguous IDs removed. Differences combine model, exporter, and approximation choices; they do not isolate model size or architecture.

Supplement S3: Average overlap differences stay positive with equal numbers of features

The difference in feature overlap is same-fact overlap minus average other-fact overlap within the same subject and test set. Within each model, subject, and test set, randomly sample the same number of features from every graph. K is the number of features in the smallest graph in that group; the second check uses half that number, rounded down. Repeat 200 times, reusing each sampled graph across comparisons within a repetition. Lines show individual test questions; diamonds show averages. Bars are descriptive 95% bootstrap intervals from resampling questions, not from the 200 feature samples. Seven of eight Gemma questions and all ten questions in each Qwen sample retain positive average differences. Qwen3-1.7B means are 0.089 for the full feature sets, 0.084 at K, and 0.033 at K/2. Equalizing counts does not remove differences in shared words, answers, or which features the exporter retains. A smaller overlap score after sampling is not a percentage of signal explained. *Qwen3-4B remains incomplete (145/147 graphs).

Supplement S4: Other-fact questions share fewer words, leaving a gap in the controls

For each test question, compare word overlap with its same-fact rewording (horizontal axis) against the highest word overlap with any other-fact rewording (vertical axis). Word overlap uses unique letter/number words, ignores letter case, and keeps common words. Both axes use Jaccard overlap: shared words divided by all distinct words across the pair. The dashed line means equal overlap; the shaded band allows a difference of 0.05 in either direction. Every other-fact comparison lies more than 0.05 below its same-fact comparison. No test question has a matched control under any of the three saved word/size matching rules: 0/8 for Gemma-2-2B, 0/10 for Qwen3-1.7B, and 0/10 for Qwen3-4B. This is a missing comparison, not a measured zero effect or proof that words explain all feature overlap. Same-fact questions also share their expected answer, so the data do not isolate meaning from words or answers. *Qwen3-4B remains incomplete (145/147 graphs).

Supplement S8: How questions become a feature-overlap comparison

Primary feature-overlap workflow for Gemma-2-2B, Qwen3-1.7B, and Qwen3-4B. The four prompt roles are starting factual, same fact reworded, invented name in the starting sentence pattern, and invented name reworded. Exact chemistry prompts about gold and iron, plus invented name zorium, are development examples from the manifest, not evaluation questions. Hosted Neuronpedia graph exports are analyzed locally without local model inference. Eligibility requires four available representations after export/integrity checks, both factual highest-probability next tokens matching the expected token after trimming whitespace, and another eligible fact in the same model, subject, and development/evaluation set. Unique learned-feature identities are (family, layer, feature ID): positions collapse, but layers remain distinct. Embeddings, logits, reconstruction-error nodes, and nodes with missing or duplicated node IDs are omitted. Jaccard overlap J is shared unique features divided by distinct features in either set. Each starting set T_i is compared with its own rewording P_i and every other included factual rewording P_j in the same model/subject/set. The baseline is the mean of all those Jaccard overlaps, excluding i; iron illustrates one comparator, not the whole pool. Subtraction yields one difference per fact, M_i. Summaries, bootstrap intervals, and permutations within the same subject area concern facts, not graph pairs. Invented-name comparisons are separate controls, not the other-fact baseline; broad output-token-type matching is not the primary eligibility rule. Illustrative feature sets and scores, not measured results: {a,b,c} and {a,b,d} share a and b (green), while c and d are unshared (white), giving 2/4=0.50; an illustrative baseline of 0.30 gives +0.20. These values do not describe the gold or iron graphs. Letters denote identities, not concepts. Arrows show analysis steps, not causal pathways; overlap alone does not establish causal use or answer correctness.
