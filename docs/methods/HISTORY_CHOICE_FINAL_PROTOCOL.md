# Final historical-date control study

Protocol prepared 5 October 2026, before any hosted outcome from these prompts. The local freeze records the timestamp, all prompts, tokenizer and executable hashes. This is a prospective follow-up motivated by observed earlier results, not a public preregistration or an amendment to the original three-model cohort.

## Question and fixed scope

Does the advantage in feature overlap for the same queried event shrink when its required answer label changes? Use Qwen3-4B with hosted `transcoder-hp` only. The primary contrast is D = (SS - DS) - (SD - DD), where the first letter means same/different queried event and the second means same/different correct A/B label. Comparisons are across the two prompt orderings. Positive D is consistent with an answer-conditioned same-event association. It is not evidence of a causal mechanism or answer-independent semantic representation.

The evaluation contains 20 event-pair blocks: ten US documentary-history pairs and ten spaceflight-chronology pairs, 40 distinct events, eight prompts per pair, 160 graphs. Event names and source-checked years are fixed in `history_choice_closeout.py` and `historical_sources.csv`. Date semantics explicitly distinguish launch, signing, enactment, adoption, ratification, and decisions. The event pairs are purposively selected, not a random sample of world history. Adjacent chronological pairs are matched as written, with no outcome-based replacement. The two themes are limited replications, not broad coverage of the history domain.

Each block crosses queried event (two), year-to-label mapping (two), and question/context order (two). All eight prompts have identical word and tokenizer-piece inventories. Event identity, query role, and order are still associated; these controls do not isolate abstract meaning. The chat template disables thinking and uses a fixed generation prefix. Expected labels must be stable single-token continuations under the pinned tokenizer. Prompts plus one answer token must fit 64 tokens. The completed offline validation is required before execution.

## Pilot and stopping rule

First request four literal A/B instruction checks, then 16 previews from two separate event-pair blocks (Declaration of Independence/Treaty of Paris and Sputnik 1/Explorer 1). The preview endpoint must return the correct top-probability label and exact normalized prompt. Each eight-cell historical pilot block must also have identical, nonempty server token multisets. All 20 checks must pass. Both literal labels are tested twice. Pilot events never enter evaluation estimates.

A scientific pilot failure stops all evaluation graph requests. Complete the fixed 20 previews to characterize it, but do not replace prompts, change gates, add models, or run another pilot. Technical failure is separate: reuse the shared serial runner's maximum three attempts, honor Retry-After, reconcile uncertain generation by slug without duplicate POSTs, and stop for review if not safely recoverable. The shared ledger counts all requests, with at least 125 seconds between starts and no more than 30 starts in a rolling hour.

On a passing pilot, collect all 160 evaluation graphs regardless of interim correctness or effect direction. Save raw graphs, prompts, returned metadata, HTTP records, SHA-256 checksums, converted graphs, and audits. Fixed graph settings: node threshold 0.8, edge threshold 0.85, maximum 10 logits, desired logit probability 0.99, maximum 5,000 feature nodes. Expected decomposition provenance is `mwhanna/qwen3-4b-transcoders`. No local inference is permitted.

## Integrity, behavioral support, and analysis population

Reject missing/ambiguous raw identifiers, orphan edges, duplicated endpoints, nonfinite weights, wrong prompt/model/source/settings, checksum failures, and converted integrity failures. Do not silently repair graph identity in this new cohort. Retain rejected files and explicit reasons. A valid eight-cell block must have matching nonempty server token inventories. All eight top labels must equal the expected A/B labels to enter the correct-response primary population. Report accuracy over every requested cell separately from graph validity; missing outputs are unavailable, not incorrect or zero overlap.

The primary analysis is available only after all 160 requests are resolved and at least 16 complete, correct blocks remain, with at least six in each theme. This fixed 80% support threshold allows limited attrition without supporting a conclusion from a small, highly selected subset. It does not guarantee representativeness or the planned precision. If the gate fails, report that the primary result is not estimable under the protocol; show exclusions and descriptive block estimates without primary significance claims. No supplementary requests replace failed blocks.

## Sample size and statistics

The independent analysis unit is the event-pair block, not a graph, feature, edge, or pairwise similarity. Twenty blocks give a Student-t 95% interval half-width of approximately 0.0234 if the block SD is 0.05; at 16 blocks it is approximately 0.0266. SD=0.05 is an explicit planning assumption, not a result estimated from a history pilot or a promised precision. The choice targets an interval half-width near 0.025 within a bounded hosted run. Observed intervals may be wider.

Primary representation: unique `(feature family, layer, feature id)` sets, collapsed across token positions, excluding embeddings, logits, and reconstruction errors. Compute all 16 cross-ordering Jaccard comparisons per block; average within SS/SD/DS/DD; compute D. Primary estimate is the unweighted mean D across supported blocks. Report each block, support by theme, a block-bootstrap 95% interval (20,000 draws, seed 20261005), a Student-t interval, and the exact two-sided block sign-flip p-value over 2^n sign assignments. This test assumes independent blocks with symmetric zero-centered contrasts under the null; neither sampling nor the test supplies randomized causal identification. There is one primary test in this follow-up (alpha 0.05). Do not pool with earlier studies, suppress earlier negative pilots, or treat this as the first outcome-independent test in the entire research program.

Secondary quantities are descriptive: balanced fact contrast, same-label and changed-label contrasts, output-label contrast, influence-weighted cosine, theme-specific means, and all valid blocks regardless of correctness. Sensitivities repeat the primary contrast after removing nodes at the final prediction position, in the last quarter of observed feature layers, or both; and after 200 independent equal-feature-count subsamples within each block. Report resampling variability separately from block uncertainty. Empty filtered representations are unavailable, never zero. These are measurement sensitivities, not causal interventions; graphs remain conditioned on the generated outputs. No significance claims are added for secondary metrics or individual themes.

## Closeout regardless of outcome

Keep this cohort separate from original expected-next-token history exclusions. A successful result supports only this fixed forced-choice task in Qwen3-4B. A null or imprecise result is retained. A failed pilot or support gate ends the study and narrows the paper. Generate the result table, source-linked figures, and completion record, then reconcile the manuscript and stop collecting data. Independent human review, redistribution permissions, and author submission approval remain explicit handoff items.
